# Jewellery Shop - One Page Portfolio

A simple static "digital visiting card" website for a jewellery shop.

## Files

- `index.html` - website
- `style.css` - styling
- `logo.webp` - replace with your real logo
- `owner.webp` - replace with shop owner's photo
- `shop.webp` - replace with shop photo

## What to edit

Open `index.html` and replace:

1. `Royal Jewellery` with your shop name.
2. `Shop No. 12, Main Market Road...` with your real address.
3. `Mr. Your Name` with the owner's name.
4. `+91 98765 43210` with the real phone number.
5. `tel:+919876543210` with the same phone number without spaces.
6. The Google Maps URL with your shop's Google Maps location/link.

## Image names

Keep these exact filenames in the same folder:

- `logo.webp`
- `owner.webp`
- `shop.webp`

The ZIP includes simple placeholder images so the page does not look broken before you add the real photos.

## GitHub Pages deployment

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save.

Your static site will then be available through GitHub Pages.
